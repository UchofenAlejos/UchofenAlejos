These projects reflect the practical mix of interests described in the profile: building useful software, integrating systems, and exploring interactive experiences. Descriptions below are limited to the information currently available in the profile README.

## Project Highlights

### Payroll & Attendance System

An administrative and Human Resources web application developed for **Inversiones CH Computer SRL**.

`Python` `Flask` `MySQL`

### ECOZEN_G4

A virtual store specializing in eco-friendly products for gardens, patios, and green areas.

`Web Development` `E-commerce`

### Cross-platform TCG Game

A **Trading Card Game** with rarity-based rewards and collection logic. It can be played in a browser, packaged for Windows with PyInstaller, and run on Android with Capacitor.

`Game Development` `Cross-platform` `PyInstaller` `Capacitor`

### Java Mini Projects

A collection of desktop applications: a music player, an ATM/POS simulator, and a mini social network.

`Java` `Swing` `Desktop Apps`

### Ferretería Pilar — Distributed Management System

A distributed hardware-store management system combining web and desktop applications. It covers customers, suppliers, products, sales, purchases, inventory, and reports; its desktop application uses Windows Forms.

`Visual Basic .NET` `.NET Framework 4.7.2` `Windows Forms` `Web` `Distributed Systems` `SQL`

### Procesadora Perú — Internal Orders App

A native Android application for managing internal orders and connecting mobile workflows to **NISIRA ERP** through web services.

`Java` `Android Native` `Web Services` `ERP Integration`
