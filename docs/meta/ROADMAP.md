| Area | Direction |
| --- | --- |

## Maintenance Priorities

- Verify project names, technologies, and descriptions before publishing changes.
- Add repository links only when the correct public URLs are known.
- Keep local links and image alt text covered by `npm run check`.
- Prefer a few useful visuals over decorative assets that add no information.

The README introduces the profile; the documentation pages provide additional detail without inventing new work or claims.
