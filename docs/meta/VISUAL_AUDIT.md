# Visual Audit

This page records the quality bar for README and documentation SVGs.

## Standards

| Requirement | Standard |
| --- | --- |
| Readability | Text remains legible at GitHub profile widths. |
| Layout | Titles, labels, and card contents do not overlap. |
| Spacing | Related content has clear gutters and padding. |
| Motion | No animation is needed to understand the visual. |
| Accessibility | Markdown image alt text and SVG descriptions explain the visual's purpose. |
| Accuracy | Visuals reflect profile facts and do not imply unlisted products or experience. |

## Main README Visuals

| Asset | Role |
| --- | --- |
| `start_here_control_surface.svg` | Routes visitors to projects, domains, and learning focus. |
| `juanpablo_core.svg` | Profile and study summary. |
| `profile_architecture.svg` | Six-project overview. |
| `tech_projects_panel.svg`, `ai_domains.svg`, `collaboration_panel.svg` | Documentation navigation. |

## Verification

Run `npm run check` for links, SVG structure, and image alt text. Preview layout changes in GitHub Markdown before merging.
