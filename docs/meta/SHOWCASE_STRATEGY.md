# Showcase Strategy

The profile should make it easy for visitors to understand who Juanpablo is, what kinds of software he has worked on, and which skills he is currently building.

## Profile Order

1. Name, location, and concise technical introduction.
2. Current studies and interests.
3. Technologies and featured projects.
4. Certifications, languages, and GitHub activity.
5. A clear LinkedIn contact path.

## Sharing Guidelines

- Keep descriptions concrete and consistent with the project information in the README.
- State learning goals as learning goals; do not present them as professional credentials.
- Link only to confirmed public profiles and project repositories.
- Keep the documentation pages aligned with the current README.
- Use visual panels to aid navigation, not to make unsupported claims.
