# Profile Style Guide

This repository is a public profile system. The design should feel technical and intentional while keeping project information easy to scan.

## Visual Direction

Use a calm, dark interface with bright signal colors, compact labels, and enough spacing for GitHub Markdown. Visuals should clarify identity, navigation, or relationships—not replace useful descriptions.

## SVG Layout

- Give headers, body content, and footer details distinct visual space.
- Keep text short and large enough to read when images are scaled down.
- Leave internal padding around labels and cards.
- Align repeated cards consistently and use clear contrast.
- Check major visual changes at typical GitHub README widths.

## Color Palette

| Role | Colors |
| --- | --- |
| Background | `#020617`, `#07111f`, `#0b1024` |
| Primary signal | `#22d3ee`, `#38bdf8`, `#67e8f9` |
| Secondary signal | `#8b5cf6`, `#a78bfa` |
| Positive signal | `#22c55e`, `#86efac` |
| Highlight | `#f59e0b`, `#fb7185` |
| Body text | `#cbd5e1`, `#94a3b8` |

## Accessibility & Spacing

- Give every embedded image descriptive alt text.
- Use SVG `<title>` and `<desc>` elements for major visuals.
- Prefer `width="92%"` for large control panels and roughly `30%` for three-card rows.
- Make navigation labels meaningful even if images fail to load.
- Keep the README useful without remote badges or animated services.

## Visual Restraint

Do not add an SVG when a short heading or text link is clearer. Favor stable profile facts and accurate project descriptions over decoration.
