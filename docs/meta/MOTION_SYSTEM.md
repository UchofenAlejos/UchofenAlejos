# Motion System

SVG motion should feel calm and should never be required to understand the profile.

## Timing Guidance

| Motion type | Duration | Guidance |
| --- | --- | --- |
| Borders | `18s–24s` | Slow, low-contrast movement. |
| Signal routes | `14s–20s` | Use sparingly to suggest direction. |
| Node pulses | `7s–12s` | Small changes only. |
| Cursor blink | `1s–1.2s` | Only for a terminal-style cursor. |

## Review

- Keep labels readable when motion is ignored.
- Avoid animating every card in one visual.
- Keep contrast and movement restrained.
- Check that no motion distracts from project descriptions.

The current profile visuals are static by default; add animation only where it improves hierarchy or meaning.
